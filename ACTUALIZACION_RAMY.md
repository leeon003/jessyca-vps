# Snapshot del código activo de Tiendas RAMY

backend/ contiene la API activa de /home/admin/jessyca-whatsapp; whatsapp/ contiene el puente de /home/admin/whatsapp-bridge. skills/ conserva las instrucciones comerciales; backend/app/ramy_sales_skill.txt es la copia utilizada en ejecución.

Incluye catálogo verificado, compras controladas, fotos reales, QR oficial y comprobantes para revisión manual. La entrega del código requiere liberación manual y consulta autorizada del estado del pedido.

El CRM está en otro repositorio: https://github.com/leeon003/Jessyca-CRM.

No se incluyen sesiones, credenciales, conversaciones ni comprobantes. No cambia servicios ni despliega automáticamente. Esta versión conserva rutas de la VPS /home/admin y requiere el CRM y tokens privados configurados fuera de Git. El instalador portable previo para /opt/jessyca no fue adaptado a estas integraciones: no usarlo como actualización de la VPS actual.

Los recursos públicos de pago referenciados por el código se versionan. Los paquetes o funciones no instalados no se incorporan a este snapshot.
